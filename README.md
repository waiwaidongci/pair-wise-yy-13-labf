# 纺织染整小样批次台账

纺织染整实验室的小样批次管理前端：从样例卡升级为完整批次台账，覆盖投染登记、Lab 三轴色差评审、复染改版与出库闭环。

## 功能

- **批次登记**：客户订单号 / 客户、面料成分（大类 + 规格）、克重、试样布重；染料 / 助剂配方按投料重量逐项登记并实时显示重量占比与总量；浴比（自动推算染液量）、分段温度曲线（起始/目标温度、升降温速率、到温保持）、保温时间、后整理方式与备注；可登记客户标准色 Lab。
- **Lab 色差评审**：录入试样 L\*a\*b\* 三轴读数，实时给出 ΔE\*ab 与 ΔL/Δa/Δb 偏色方向（明暗、红绿、黄蓝）；提交后出具书面色差结论。
  - 规则：ΔE ≤ 1.0 评审通过；**ΔE > 1.0 判不合格并自动转入复染**（也可人工转复染）。
- **复染改版闭环**：复染中修改配方或工艺会生成新版本，旧版本标记作废、评审结论与读数原样保留；批次回到待评审，**复染再次评审通过后才能办理出库**；出库后批次只读归档。
- **批次列表**：按客户订单号（兼容批次号 / 客户关键字）与评审状态（待评审 / 复染中 / 评审通过 / 已出库）筛选；展开行可见配方重量比例、工艺曲线摘要、Lab 评审面板、版本留痕与操作日志。
- **断点续做**：台账、筛选/展开状态、未提交的 Lab 读数、未保存的登记草稿均存 localStorage，重开页面可继续处理（工具栏出现「继续未完成的登记」入口）。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `src/domain/ledger.ts` | **批次账**：批次数据模型、登记校验、版本管理、评审入账、转复染、出库、筛选统计、localStorage 持久化、样例卡数据 |
| `src/domain/reviewRules.ts` | **评审规则**：Lab 色差 ΔE\*ab 计算、三轴偏色结论、1.0 复染阈值、配方重量比例、浴比染液量、温度曲线摘要 |
| `src/domain/pageState.ts` | **页面操作**：筛选 / 展开 / 读数草稿等页面状态与表单草稿的持久化、空草稿、批次→草稿映射 |
| `src/domain/types.ts` | 三个业务文件共享的类型定义 |
| `src/components/`、`src/App.tsx` | 页面组件与操作编排（不含业务规则） |

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62012
npm run build    # 生产构建
node scripts/test-domain.mjs   # 领域逻辑测试（色差判定 / 复染流转 / 版本留痕 / 出库门槛）
```

数据仅保存在浏览器本机；「恢复样例」按钮可清空并重置为 3 张初始样例卡。
